Slug Gaming Operations Dashboard

An anonymized operations and analytics dashboard connecting community growth, event performance, esports room usage, program activity, budgets, recruitment, and external partnerships.

Project Overview

The Challenge

Slug Gaming operated across events, esports, partnerships, recruitment, budgeting, community growth, and a shared gaming room. The organization had useful data, but it was stored across separate spreadsheets and was difficult to review as one operating system.

I organized the information into one centralized dashboard so performance could be reviewed more quickly and decisions could be supported by measurable results.

My Role

As President of Slug Gaming, I helped lead operations, partnerships, event execution, officer workflows, and the organization’s community growth.

For this project, I cleaned and anonymized the source data, structured the workbook, selected key performance indicators, and designed the final dashboard.

Key Results

Interactive Dashboard

The embedded dashboard includes community, event, esports room, program, financial, recruitment, merchandise, and external partnership data.

Dashboard Areas

  • Community and events: tracked member growth, signups, attendance, and event performance.
  • Esports room operations: organized more than 500 recorded uses to understand utilization.
  • Partnerships: summarized external company relationships and sponsorship support.
  • Programs and operations: connected officer workflows, recruitment, event execution, budgeting, reimbursements, and merchandise demand.
  • Privacy: removed names, emails, handles, addresses, confidential responses, and other personally identifiable information.

Tools and Skills

Excel Data Cleaning Data Analysis Dashboard Design KPI Definition Charts Formulas Operations Partnerships Process Improvement

What I Learned

This project showed me how operational data becomes more useful when it is connected to a clear decision. Instead of treating attendance, room usage, budgets, recruitment, and partnerships as separate activities, I designed the dashboard to show how they contributed to the organization’s overall growth.

It also strengthened my experience with data privacy. The original files included information that should not appear in a public portfolio, so anonymization and aggregation were treated as core parts of the project rather than final cleanup steps.
